# Почему пользователи нажимают «Ответ мне не помог»

Исследование качества ответов RAG-чатбота поддержки Ozon: 119 992 диалога «вопрос → ответ RAG → кнопка реакции».

| Что | Где |
|---|---|
| Итоговый отчёт | [`report/REPORT.md`](report/REPORT.md) · [`REPORT.pdf`](report/REPORT.pdf) · [`REPORT.docx`](report/REPORT.docx) |
| Презентация | [`presentation/omnp_presentation.pptx`](presentation/omnp_presentation.pptx) · [`PDF`](presentation/omnp_presentation.pdf) |
| Код (воспроизводимый, Colab) | [`notebooks/omnp_analysis.ipynb`](notebooks/omnp_analysis.ipynb) |
| Дашборд | [`dashboard/index.html`](dashboard/index.html) — открыть в браузере |
| Таблицы и графики | [`outputs/tables/`](outputs/tables/), [`outputs/figures/`](outputs/figures/) |

## Главное

- **36% всех ОМНП** — запросы, где нужно действие или данные по своему заказу («где мой заказ», «отмените», «верните деньги»). Бот отвечает на них общей инструкцией.
- **Тип потребности важнее темы.** «Узнать» получает 76% ОМНП, «решить по своему заказу» — 89%, жалоба или запрос оператора — 93%.
- **Формат ответа.** Прямой «Да» / «Нет» первым словом снижает шансы ОМНП в 2,5 раза. «Список возможных причин» вместо ответа повышает их в 1,6 раза.
- **Кнопки — шумная метрика.** «Человек» даёт 99% ОМНП (так попадают к оператору), «назад» — 41% (так выходят из диалога).

## Как воспроизвести

**Google Colab.** Откройте ноутбук в Colab и выполните `Runtime → Run all`. Ноутбук сам:
- поставит зависимости;
- склонирует репозиторий ради папки `data/`;
- попросит загрузить `Датасет для ВШЭ.xlsx`.

Эмбеддинги считаются около 5 минут на GPU.

**Локально:**
```bash
pip install -r requirements.txt
# положить «Датасет для ВШЭ.xlsx» в корень репозитория
jupyter nbconvert --to notebook --execute notebooks/omnp_analysis.ipynb
```

Результаты детерминированы (`SEED = 42`): точки назначаются кластерам по сохранённым центроидам.

## Структура

```
data/                    центроиды и названия кластеров, ручная разметка 210 диалогов
notebooks/               анализ целиком
outputs/figures|tables   графики и таблицы, key_facts.json — все цифры отчёта
report/                  отчёт (md / pdf / docx)
presentation/            презентация (pptx / pdf)
dashboard/               интерактивный дашборд (Plotly, один HTML-файл)
cache/                   кеш эмбеддингов (не в git, пересоздаётся)
```

Исходный датасет и ТЗ не входят в репозиторий (см. `.gitignore`).
